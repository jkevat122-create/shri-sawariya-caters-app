SHRI SAWARIYA CATERS — PWA APP

UPLOAD THESE 5 FILES TO THE ROOT OF YOUR WEBSITE HOSTING:
1. index.html
2. manifest.json
3. sw.js
4. icon-192.png
5. icon-512.png

IMPORTANT: Keep all five files in the same folder (website root). Do not rename them.

INSTALL ON ANDROID:
1. Publish the website on HTTPS (for example GitHub Pages or Netlify).
2. Open the published website in Google Chrome.
3. Wait a few seconds. If the Install App button appears, tap it.
4. If it does not appear: Chrome menu (⋮) > Install app / Add to Home screen.

PWA REQUIREMENTS:
- HTTPS hosting is required (localhost also works for testing).
- This package keeps the existing Sawariya Caters website design and adds install support plus an offline app shell.
- External images and third-party links may still need internet access.
